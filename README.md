# MGV Touch Hair Wigs Try-On App

A virtual wig try-on experience built with React and Vite. The app lets users upload a portrait or start a live camera mirror, choose a wig style, adjust fit, and receive AI-style fit guidance for different face shapes.

## Features

- Virtual wig styling interface
- Photo upload and live camera support
- Fit analysis and recommendation logic
- Wig style catalog and custom wig upload
- Responsive luxury storefront styling

## Local development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local app in your browser:

- http://localhost:5173/

## Production build

```bash
npm run build
```
